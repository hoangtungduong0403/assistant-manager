# Checklist

□ Đã đọc file Client Information.

□ Đã xác định đúng số lượng khách hàng.

□ Đã đọc Template Summary Quotation.

□ Đã mapping dữ liệu vào đúng cột Summary Quotation cho từng khách hàng.

□ Đã thêm đủ số dòng mới tương ứng số khách hàng vào Summary Quotation (không thiếu, không thừa).

□ Đã lưu Summary Quotation theo đúng quy ước đặt tên.

□ Đã đọc Template Single Quotation.

□ Đã mapping dữ liệu đúng khách hàng vào từng file Single Quotation (không lấy nhầm dữ liệu khách hàng khác).

□ Đã sinh đủ số file Single Quotation tương ứng số khách hàng.

□ Đã lưu từng file Single Quotation theo đúng quy ước đặt tên.

□ Đã ghi rõ "Chưa được cung cấp" cho các trường bắt buộc bị thiếu (nếu có).

□ Đã tổng hợp kết quả (số khách hàng đã xử lý, danh sách Artifact đã sinh).
