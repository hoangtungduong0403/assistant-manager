# Điều kiện hoàn thành Mission

Mission chỉ được xem là hoàn thành khi:

- Đã đọc toàn bộ dữ liệu từ file Client Information.
- Đã thêm đúng số dòng vào Summary Quotation (1 dòng / khách hàng, khớp chính xác với số khách hàng trong Client Information).
- Đã mapping đầy đủ dữ liệu vào đúng cột theo Template Summary Quotation.
- Đã sinh đủ số file Single Quotation (1 file / khách hàng, khớp chính xác với số khách hàng trong Client Information).
- Đã mapping đúng dữ liệu của từng khách hàng vào đúng file Single Quotation tương ứng (không lẫn dữ liệu giữa các khách hàng).
- Đã lưu toàn bộ Artifact (Summary Quotation + các Single Quotation) theo đúng quy ước đặt tên.
- Không còn trường thông tin bắt buộc bị bỏ trống (trừ khi dữ liệu nguồn không cung cấp, và đã ghi rõ "Chưa được cung cấp").

Nếu bất kỳ điều kiện nào chưa đạt, Mission chưa được coi là hoàn thành.
